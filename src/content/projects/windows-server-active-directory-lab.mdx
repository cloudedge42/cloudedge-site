## Overview

I built a virtual Windows Server and Windows desktop lab to practise tasks found
in an IT support environment. It gave me a place to explore domain
administration, user accounts, access permissions and workstation configuration.

## Environment

I initially used Oracle VM VirtualBox. I later began recreating the environment
in VMware Workstation, including installing a Windows 11 client.

The original lab used a domain controller named DC01 and the domain lab.local.

## Practical work

- Setting up a Windows Server Active Directory domain.
- Joining Windows workstations to the domain.
- Creating and managing users, security groups and organisational units.
- Practising password resets, account unlocking and access administration.
- Configuring shared folders, NTFS permissions and group-based access.
- Working with Group Policy and mapped network drives.
- Practising DNS resolution, IP addressing and connectivity troubleshooting.

## What I learned

The lab helped me understand how user accounts, computers, permissions and
policies fit together in a Windows domain. It also gave me practical experience
with support tasks such as resetting passwords, unlocking accounts and
investigating access or connectivity problems.

## Relevance to IT support

This project supports my move into IT support by giving me practical familiarity
with Windows administration and common account and access tasks.
