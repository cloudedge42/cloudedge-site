This project reviewed page structure and interaction patterns to remove common
accessibility barriers.

## What I changed

- Updated heading order to improve document structure
- Added clearer link and button labels for screen reader users
- Improved focus visibility and keyboard navigation behavior

## Result

Pages are easier to navigate and understand for both keyboard and assistive
technology users.
